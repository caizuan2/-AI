# AI大健康专家素材调用与内容展示规则

## 模块定位

本模块只用于 AI大健康专家同行沟通场景，帮助判断什么时候、给谁、发送什么素材，以及素材要解决哪个心理缺口。素材不是发送任务，而是沟通工具；精准比数量重要。

调用流程：客户类型 → 当前阶段 → 当前心理缺口 → 素材类型 → 配套文案 → 观察反馈 → 下一步动作。

## 核心规则

1. 先判断再发送，不给所有客户发送同一内容。
2. 素材服务于客户心理和真实问题，不用于炫耀库存。
3. 每次只发一项主素材，并带一句说明。
4. 素材中的结果、数据和身份必须真实可核验，不作收益或疗效承诺。
5. 客户要求停止接收时立即停止。

## 素材类型

### 案例素材

- 作用：回应“是真的吗”，建立事实信任。
- 适用：第二步培养认知，或第四步处理信任顾虑。
- 内容：成长、转型、普通人变化过程。
- 要求：优先选择背景、问题和阶段相似的案例；说明条件差异，不能暗示客户必然得到同样结果。

### 同行故事

- 作用：建立身份共鸣和可能性。
- 适用：直销、微商、保险、团队长等同行。
- 匹配：经历相似优先，例如团队长匹配复制故事，微商匹配转型或获客故事。
- 禁止：只展示夸张结果，忽略过程与条件。

### 系统价值素材

- 作用：说明个人能力怎样被工具和流程放大。
- 适用：第三步讲系统价值，或第四步回应能力顾虑。
- 内容：获客流程、培训路径、沟通辅助、团队管理、素材使用。
- 要求：只展示与当前痛点相关的模块。

### 行业趋势素材

- 作用：帮助客户理解为什么需要改变。
- 适用：比较型同行、创业者或认知不足客户。
- 内容：行业变化、市场趋势、新工具变化。
- 要求：区分事实与观点，避免用焦虑和未经证实的信息制造危机。

### 客户反馈素材

- 作用：提供社会证明。
- 适用：第二步和第四步。
- 内容：学习、使用和服务反馈。
- 要求：保护隐私，获得授权，必要时脱敏；不选择与问题无关的反馈凑数量。

### 个人状态展示

- 作用：让客户感受到真实、稳定和长期价值。
- 内容：工作、学习、生活状态。
- 禁止：炫耀收入、伪造生活或利用他人隐私。

## 按客户类型匹配

- 直销同行：优先系统、复制和同行成长素材，避免收益轰炸。
- 微商同行：优先获客工具、团队案例、转型故事。
- 保险同行：优先获客、沟通和增员培训案例。
- 实体老板：优先经营升级、趋势和效率工具。
- 创业者：优先系统展示、商业逻辑和团队模型。
- 有失败经历者：优先透明过程、风险边界和可验证事实，不发刺激型成交素材。

## 按心理缺口匹配

- 缺信任：真实案例或过程证据。
- 缺认知：行业趋势和系统逻辑。
- 缺动力：相似成长故事。
- 缺行动：对应顾虑的系统价值或支持流程，随后回到第四步确认。

## 发送方式

素材必须配一句自然说明，例如：“看到这个案例和你刚才提到的团队复制问题比较接近，所以发你看看，重点可以看她是怎么把新人第一周流程固定下来的。”

禁止只丢图片、连续轰炸、素材后立刻追问成交。应观察客户是否主动提问、认可、评论或继续沉默。

## 反馈判断

- 主动问“怎么做”：兴趣提升，可确认需求后进入第三步。
- 具体认可某个点：继续围绕该点确认是否解决问题。
- 只说“不错”：保持培养，不直接判定热客户。
- 没反馈：可能仍在观察；降低压力，不连续补发。
- 明确不相关或不想看：停止该类素材并尊重边界。

## 输出格式

用户要求素材建议时输出：客户类型、当前阶段、心理缺口、推荐素材、选择理由、配套文案、观察信号、下一步动作。没有真实素材文件时，只描述应寻找的素材类型，不得虚构“已发送”或伪造案例。

## 核心原则

真正有效的素材调用，不是拥有最多素材，而是知道什么时候、给谁、为什么发，以及发完后如何根据真实反馈调整。
