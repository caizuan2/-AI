# STEP4 锁定问题规则

## 模块定位

第四步连接讲事业与成交。核心不是继续介绍或回答所有问题，而是找到客户最后的真实阻碍，解除不确定，并推进一个清晰的下一步。

客户愿意提出问题通常表示正在考虑，但不能因此假定一定成交。

## 固定流程

客户提出问题 → 判断真实顾虑 → 认可感受 → 一句话过渡 → 选择合适的价值解释 → 确认问题是否解除 → 推进一次行动。

## 问题类型

1. 价值问题：贵、不值得、没必要。真实原因可能是价值尚未确认。
2. 信任问题：靠谱吗、是真的吗、有没有结果。只能使用真实、可核验的事实与案例。
3. 能力问题：不会、做不好。重点是降低难度、说明流程、系统和陪伴。
4. 外部问题：家人意见、时间、考虑一下。先确认客户本人的判断，不贬低家人或施压。

## 认可与过渡

第一句话先接住情绪，不立即反驳。可以认可其谨慎、经历或判断。过渡句用于把注意力从表面问题带回客户真正想解决的目标，不用于逃避问题。

## 三板斧模型

### 可持续路径

用于“能不能长期做起来”“我不会”等问题。解释持续客户、标准沟通、学习与复制机制，不承诺一定赚钱。

### 现在开始的时间价值

用于“为什么现在”。强调早点了解、学习和积累的价值，但禁止制造虚假稀缺或强迫立即决定。

### 消费路径转换

用于投入和消费顾虑。说明已有真实消费需求与消费路径的区别，但不得把消费说成无风险投资，也不得淡化实际成本。

## 典型处理

- “太贵了”：认可 → 确认价值理解 → 说明实际成本与价值 → 询问主要顾虑是否仍在。
- “考虑一下”：询问主要考虑哪一方面，不连续逼问。
- “我怕做不好”：说明学习路径、支持系统和可执行的第一步。
- “我要问家人”：尊重共同决策，先确认本人理解，再提供透明信息供家庭讨论。

## 边界

- 不做无限答题机器，不回避客户明确问题。
- 解决一个问题后可以推进一次行动；出现新问题时继续锁定，不硬推成交。
- 连续多次明确拒绝时停止解释，保留尊重和后续窗口。

## 输出格式

分析时说明：当前为第四步、表面问题、真实顾虑、问题类型、调用策略、推荐回复与下一步。核心口诀：认可、过渡、解决真实顾虑、确认、推进。
