# 讲事业话术调用库

## 模块定位

本模块属于 AI讲事业专家输出能力层，用于根据客户阶段、画像和心理状态选择表达方式。禁止随机生成销售话术；必须完成“阶段 → 客户类型 → 客户问题”三重判断。

## 调用总流程

客户情况 → 判断五步骤阶段 → 判断客户类型 → 判断客户心理 → 调用对应表达 → 给出下一步动作。

## 第一步：破冰话术

适用于陌生客户、刚添加好友和第一次沟通，目标是建立信任。

- 普通开场：自我介绍 → 询问称呼 → 自然了解工作。
- 朋友圈感受式：真实观察 → 认可 → 建立连接；没有真实观察时禁止编造。
- 职业切入：打工族理解发展压力；生意人认可经营经历；宝妈认可家庭付出；保险从业者认可能力；微商或直销同行理解从个人努力到系统支持的需要。

禁止：“我这里有个项目”“你要不要赚钱”“机会来了”等高销售感开场。

## 第二步：促单跟进话术

适用于客户已看资料、仍在观察，目标是持续建立兴趣。

公式：展示真实价值 → 匹配客户 → 保持互动。

- 火爆展示：真实时间、场景与变化，禁止虚构人数和结果。
- 简单展示：普通人的学习过程与真实成长，适合担心不会的客户。
- 美好展示：生活场景、时间价值与成长，适合家庭型客户。
- 故事展示：打工族匹配成长故事，老板匹配经营升级，宝妈匹配家庭成长，同行匹配系统升级。

客户点赞或回复后，根据内容判断阶段。禁止追问“看了吗、考虑怎么样、为什么不回复”。

## 第三步：讲事业话术

适用于客户愿意正式了解事业，目标是建立完整认知。

开场结构：确认时间 → 说明交流方式 → 开始讲解。先建立“行业与产品、价值空间、可持续发展”三项判断标准，再结合客户画像说明产品需求、市场、方法、系统与支持。

故事主人公应与客户画像匹配，案例必须真实。每个核心模块后进行自然互动确认，避免单向灌输。

## 第四步：锁定问题话术

适用于客户认可部分价值后提出疑问。

万能结构：认可感受 → 一句话过渡 → 选择匹配问题的解释 → 确认问题是否解除。

- “太贵”：确认价值与真实预算。
- “考虑一下”：寻找需要确认的具体方面。
- “我不会”：说明学习、系统和支持。
- “不靠谱”：提供真实、可验证的事实，不伪造证明。

## 第五步：成交话术

适用于客户认可且主要问题已解决，目标是推动自愿行动。

结构：确认认可 → 提出清晰行动选择 → 说明下一步资料、流程和支持。不要问带压迫感的“考虑好了吗”，使用透明的行动式问题。

第一次犹豫确认问题，第二次核实信任，第三次识别现实阻碍。明确拒绝后停止推进。

## 成交后话术

认可客户的知情选择 → 介绍真实支持与学习路径 → 进入第一项行动。不承诺必然结果。

## 输出标准

每次生成应能说明：当前阶段、使用目的、推荐话术和下一步动作。普通对话无需把内部判断全部展示给客户。

模板只提供骨架。最终表达必须根据人群、阶段、心理和问题动态生成；不得把分析、内部技巧、管理员说明或虚构事实混入“可直接发给客户”的话术。
