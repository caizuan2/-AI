# AI讲事业专家知识库索引

## 文档定位

本文件是 AI讲事业专家固定知识库导航中心，帮助模型从客户问题定位当前阶段、对应规则和输出模块。只服务 `expert-career / kb-business-coach` 范围，不得跨 Agent 使用。

## 知识结构

### 总控制

- `AGENTS.md`：角色、固定作用域、五步骤、模型原文保护和输出边界。
- `AI讲事业专家执行工作流.md`：收到客户信息后的运行顺序。

### 五步骤规则

- `01_破冰规则.md`：新客户、第一次聊天、不了解你、如何开场。
- `02_促单跟进规则.md`：已看资料、没有回复、仍在观察、长期关注。
- `03_讲事业规则.md`：主动了解模式、愿意电话或语音、想知道具体怎么做。
- `04_锁定问题规则.md`：贵、考虑、靠谱吗、没时间、不会、比较等异议。
- `05_成交规则.md`：已经认可，询问如何开始、资料、流程和行动。

### 判断系统

- `客户心理判断模型.md`：所有客户分析任务优先读取，判断阶段、温度、心理和隐藏需求。
- `行业客户画像库.md`：有职业或身份信息时，匹配可能痛点、沟通方向和案例类型。

### 输出系统

- `讲事业话术调用库.md`：需要生成开场、共鸣、转场、异议回应和行动推进时调用。
- `异议处理数据库.md`：只在第四步、第五步出现具体阻碍时调用。

## 自动调用表

| 用户输入 | 阶段 | 规则组合 |
| --- | --- | --- |
| 新客户怎么聊 | 第一步 | 破冰规则 + 行业画像 |
| 客户不回复 | 第二步 | 促单跟进 + 心理模型 |
| 客户想深入了解事业 | 第三步 | 讲事业规则 + 行业画像 |
| 客户说贵、怕被骗、不会 | 第四步 | 锁定问题 + 异议数据库 |
| 客户认可但说再考虑 | 第四步或第五步 | 先判断真实顾虑，再调用异议数据库与对应阶段 |
| 客户问怎么加入 | 第五步 | 成交规则 |
| 分析完整聊天记录 | 按证据判断 | 工作流 + 心理模型 + 画像 + 当前阶段 |
| 生成下一句话 | 当前阶段 | 当前阶段规则 + 话术调用库 |

## 读取优先级

1. `AGENTS.md`：确认角色、作用域和硬边界。
2. `INDEX.md` 与执行工作流：确认调用顺序。
3. 客户心理判断模型：判断状态。
4. 行业客户画像库：判断客户类型。
5. 当前阶段规则：只加载当前步骤；完整框架问题才加载五步。
6. 话术调用库；第四步或第五步再加载异议数据库。

## 禁止错误调用

- 新客户不得直接调用成交规则。
- 客户提出价格问题不得只回答价格，必须确认真实顾虑。
- 不得让所有客户使用同一模板。
- 不得把内部分析或规则名当成给客户的话术。
- 不得修改 Provider 返回的原始 Markdown 正文。

## 标准分析要素

客户阶段、客户类型、表面表达、真实心理假设、当前目标、调用模块、推荐动作、推荐话术。信息不足时明确需要确认的事实。

## 最终调用链

用户输入 → 总规则 → 执行工作流 → 心理判断 → 行业画像 → 当前步骤规则 → 话术调用 → 必要时异议数据库 → 下一步沟通方案。
