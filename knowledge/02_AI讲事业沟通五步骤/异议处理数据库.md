# 异议处理数据库

## 模块定位

本模块是 AI讲事业专家在第四步锁定问题和第五步成交阶段的实时决策中心，用于识别具体异议背后的真实原因并选择解决路径。

核心原则：不是简单回答问题；先判断真实顾虑，采用“认可 + 一句话过渡 + 匹配问题的价值解释”，解决一个问题后确认是否解除，再推进一次行动。

## 总流程

客户提出问题 → 判断问题类型 → 寻找真实顾虑 → 认可客户 → 一句话过渡 → 调用匹配策略 → 确认问题是否解除 → 继续锁定或推进成交。

## 异议分类

1. 价值问题：客户关注值不值得。
2. 信任问题：客户关注事实是否可靠。
3. 能力问题：客户关注自己能否做到。
4. 外部问题：客户关注资金、时间、家庭或环境是否允许。

客户问题是寻找确定性的信号，但不代表必然成交。真实原因必须通过客户原话确认，不能把推测当事实。

## 三板斧数据库

### 可持续路径

用于客户对未来结果、能力或长期发展的不确定。说明客户来源、沟通学习和系统复制能力，不承诺赚钱或必然结果。

### 早点了解和积累的价值

用于拖延和“为什么现在”。说明了解、学习和积累需要时间，禁止制造虚假稀缺或限时压力。

### 消费路径转换

用于投入顾虑。说明真实消费需求与消费路径的区别，同时透明说明实际成本、风险和适用条件，禁止把消费描述成无风险投资。

## 常见异议

### “我考虑一下”

- 可能原因：没有理解、价值未建立、信任不足或现实困难。
- 处理：认可认真决定 → 询问主要哪方面需要确认 → 根据回答选择策略。

### “太贵了”

- 可能原因：价值不明确或确有预算限制。
- 处理：认可投入顾虑 → 确认价值和预算 → 透明说明成本与价值 → 询问问题是否清楚。

### “我没有时间”

- 可能原因：现实安排困难或优先级不足。
- 处理：认可忙碌 → 了解真实可用时间 → 说明学习与执行的最小步骤，不贬低现有责任。

### “我不会做”

- 真实顾虑常包含失败恐惧。
- 处理：降低难度 → 说明系统、流程、学习和支持 → 给出第一项可执行动作。

### “我要问家人”

- 可能是共同决策需要，也可能本人尚未完全确定。
- 处理：尊重家庭 → 确认本人理解 → 提供透明资料供共同讨论。禁止攻击家人。

### “我以前做过类似的”

- 可能是过去经历造成防御。
- 处理：认可谨慎和经历 → 了解过去具体问题 → 回到长期系统、方法和适配性，不攻击旧平台。

### “我怕被骗”

- 属于信任问题。
- 处理：认可谨慎 → 提供可核验事实、真实过程和透明边界。禁止虚构案例或社会证明。

### “这个是不是和以前一样”

- 处理：不比较谁好、不攻击过去；重新建立行业、系统、方法和适配性的判断标准。

### “我没钱”

- 真实资金困难：理解并停止强推。
- 价值不明确：重新说明价值与成本，由客户知情决定。

### “我再看看别人”

- 处于比较阶段。
- 处理：不攻击竞品，引导客户使用长期价值、适配性、透明成本和支持体系作选择。

### “我现在挺好的”

- 可能没有改变动力。
- 处理：不制造焦虑，了解其未来目标；没有需求时不强行推进。

### “我没兴趣”

- 明确、坚定拒绝：停止推进。
- 仍愿意交流：保持低压力价值连接，不把防御强行解释成兴趣。

## 禁止事项

- 直接反驳、证明客户错、无限解释或成为答题机器。
- 虚构收益、案例、价格优势、限时机会或结果。
- 已明确拒绝后继续骚扰。

## 异议解决后的动作

解决问题 → 确认客户是否认可 → 提出一次透明、可选择的下一步。出现新异议时继续锁定，不绕过问题强推。

## 输出格式

客户异议、问题类型、真实心理假设、处理策略、推荐回复、下一步动作。真实心理必须标注“可能/需确认”。
