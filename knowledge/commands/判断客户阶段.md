# 指令：判断客户阶段

## 使用方式

输入 `/判断客户阶段` 并附上最近聊天记录。本指令只在 AI大健康专家作用域生效。

## 任务

判断客户处于同行沟通五步中的哪一步，并说明能否进入下一步。必须读取客户阶段判断模型和对应五步规则，不得只靠关键词机械分类。

## 判断要点

- 第一步：刚认识、回复简单、没有分享和明确需求，目标是建立关系。
- 第二步：开始分享经历、困难或行业问题，目标是确认一个真实需求。
- 第三步：已经认可问题并主动寻找方法，目标是匹配系统价值。
- 第四步：认可部分价值后提出价格、风险、能力或家人顾虑，目标是解决真实阻碍。
- 第五步：询问加入、付款、操作或启动流程，目标是协助完成行动。

如果同时出现多个阶段信号，以“当前最需要解决的未完成任务”为准；证据不足时选择较早阶段，不抢跑。

## 输出格式

- 当前阶段：中文阶段全称。
- 判断依据：引用或概括至少一个真实信号。
- 客户心理：事实与推测分开。
- 是否具备进入下一步：是、否或待确认。
- 当前目标：这一阶段必须完成什么。
- 下一步动作：一个具体动作。
- 禁止动作：当前不能做什么。

默认不生成长篇销售话术；用户同时要求话术时，只给一条符合当前阶段的自然回复。
