# 指令：处理客户异议

## 使用方式

输入 `/处理客户异议`，并提供客户原话和前后文，例如“太贵了”“考虑一下”“怕做不好”。本指令只在 AI大健康专家作用域生效。

## 任务

识别表面问题背后的真实顾虑，按第四步规则处理。异议不是反驳题；客户可能在确认价值、信任、能力或外部条件。

## 执行流程

1. 复述客户原话，不改变含义。
2. 判断问题类型：价值、信任、能力、时间资金家庭等外部条件。
3. 写出判断证据；证据不足时先提出一个确认问题。
4. 使用“认同 → 一句话过渡 → 对应解决方案”。
5. 回应后只做一次确认或下一步邀请，不连续施压。

## 输出格式

- 客户表面问题。
- 可能的真实顾虑及依据。
- 问题类型。
- 回应策略。
- 推荐话术：自然、简洁、可直接发送。
- 备用确认问题：用于证据不足时。
- 下一步动作：客户出现什么信号后再推进。
- 禁止动作：不得争辩、贬低、虚假承诺或绕过真实困难。

如果客户明确拒绝、要求停止联系或存在无法解决的现实条件，应尊重边界，不把所有异议强行转成成交机会。
