# 指令：生成电话沟通方案

## 使用方式

输入 `/生成电话沟通方案`，并提供客户背景、最近聊天、已确认需求和电话时长。本指令只在 AI大健康专家作用域生效。

## 任务

根据客户当前阶段设计电话流程。电话可以跨越相邻阶段，但不能跳过尚未完成的任务，也不能把所有五步机械讲完。

## 电话结构

1. 开场连接：确认时间是否方便，回顾真实聊天连接点。
2. 当前阶段任务：围绕当前最重要问题展开。
3. 关键问题：最多三个，采用回应、共鸣、提问的节奏。
4. 价值连接：只有客户承认问题后，才讲与该问题对应的系统能力。
5. 顾虑确认：客户提出疑问时先识别真实顾虑。
6. 收口动作：约定一个清楚、双方同意的下一步。

## 输出格式

- 客户分析：画像、心理、中文阶段及证据。
- 电话目标：一个主目标和一个最低目标。
- 建议时长：根据内容给出区间。
- 沟通顺序：按分钟或模块列出。
- 关键问题：自然、不审问。
- 推荐表达：开场、过渡和收口各一条。
- 风险提醒：不能触碰的内容。
- 成功信号：达到什么状态即停止继续输出。

资料不足时先列出电话前需要确认的信息，不虚构完整客户档案。
