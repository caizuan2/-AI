# 指令：生成客户跟进计划

## 使用方式

输入 `/生成客户跟进计划`，并提供客户状态、最近互动、当前阶段和已知时间安排。本指令只在 AI大健康专家作用域生效。

## 任务

依据客户跟进策略模型制定未来七天的跟进节奏。计划必须与客户温度、等级和阶段匹配，不等于每天发送消息。

## 分级策略

- 冷客户：低频价值维护，目标是恢复连接。
- 温客户：规律互动，目标是确认需求和提升认知。
- 热客户：及时解决顾虑并完成下一项明确行动。
- 已明确拒绝或要求停止联系：停止计划，尊重边界。

## 输出格式

- 客户等级：S、A、B或C，并说明证据。
- 当前阶段：中文阶段全称。
- 当前心理和核心需求。
- 七天唯一主目标。
- 未来七天动作：只在有必要的日期安排，写明方式、内容和目的。
- 推荐发送内容：文字、案例、素材或电话邀请，并说明匹配理由。
- 观察信号：什么反馈代表升级、保持或降频。
- 下一次沟通时间或建议窗口。
- 禁止动作。

用户未提供具体日期、时区或客户作息时，不编造精确时间；使用相对时间并标记需要确认。计划结束后安排一次复盘，而不是无限自动跟进。
