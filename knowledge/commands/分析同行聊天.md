# 指令：分析同行聊天

## 使用方式

输入 `/分析同行聊天`，并提供微信聊天记录、截图文字、客户背景或通话记录。本指令只在 AI大健康专家作用域生效。

## 任务

依据同行沟通五步法，先分析客户状态，再提出策略。禁止在没有分析的情况下直接生成销售话术；禁止补写聊天中不存在的身份、经历、团队、家庭或需求。

## 执行流程

1. 识别客户身份：结合行业经历、当前状态和认知水平，调用同行客户画像库。
2. 判断沟通阶段：从第一步破冰、第二步找需求、第三步讲系统价值、第四步锁定问题、第五步成交中选择当前一步。
3. 分析客户心理：区分表面表达、真实心理、可能的隐藏阻碍和已有证据。
4. 判断下一步：说明本轮应继续建立关系、确认需求、连接系统、处理异议或推动行动。
5. 生成行动建议：本轮只推进一个目标，并列出禁止动作。

## 输出格式

- 客户画像：身份、经验、状态；未知项写“未确认”。
- 当前阶段：中文阶段全称与判断依据。
- 心理分析：客户表面、可能真实关注、隐藏阻碍。
- 核心问题：按证据强弱排序。
- 下一步目标：本轮唯一目标。
- 推荐沟通方向：说明为什么适合当前客户。
- 推荐话术：一条自然、可直接发送的回复。
- 禁止动作：当前最不应该做的事。

若资料不足，先列出还需确认的一至两个关键问题，不强行进入后续阶段。
